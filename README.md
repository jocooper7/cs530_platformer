# Basic Arcade Platformer
A simple proof-of-concept arcade platformer built for CS 530: AI Applications 
and Principles at Southern New Hampshire University, using only AI prompting.

**Author:** Jo Cooper  
**Requirements:** Python 3.x, Pygame (`pip install pygame`)

## Setup
Run via:
```bash
python main.py
```

## About
This program contains a single-level platformer proof of concept, 
created exclusively using AI prompting best practices as part of a 
course assignment.

## Controls
- A and D are used for left and right movement respectively
- spacebar is used for jump
